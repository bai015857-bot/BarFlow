# 鼠标侧键切换桌面

## 使用方式

“侧键切桌面”页提供独立启用开关及方向互换。常见鼠标的第4、5按键（Core Graphics 按钮编号3、4）分别映射到左、右桌面。默认关闭，升级保留已有设置且不会自动开启新监听。普通启动恢复用户明确保存的启用值；`--safe-mode` 和 `--smoke-test` 不启用侧键。

需要手动授予辅助功能权限、至少两个桌面，以及可用的系统“向左／向右移动一个空间”快捷键。缺少权限或快捷键不可用时不启动侧键监听，并显示中文原因。鼠标驱动若已将侧键转换成键盘事件，需先恢复原侧键映射；本版不提供任意键码学习。

开启后只接管这两个侧键，原网页前进／后退作用被替代。按住控制、选项、上档或命令键时保留原点击，不改变左、右、中键与滚轮。长按只发送一次，250毫秒内的额外点击整对限速；最左或最右桌面边界是否移动由系统决定，不实现循环。

## 生产路径

- `SideButtonPolicy`：按钮映射、来源元数据过滤、按下/抬起配对、长按去重和限速。
- `SideButtonEventProcessor`：真实 CGEvent 转换到策略，并构造快捷键事件序列。
- `SideButtonShortcuts`：只读解析系统符号快捷键79、81（左、右），默认 ⌃← 和 ⌃→。系统偏好是稀疏覆盖域，不是完整快照；有效的仅启用覆盖应继承对应默认，显式畸形值应拒绝。
- `SideButtonKeyboardBuilder`：先完整构造修饰键按下、主键按下/抬起、修饰键释放的序列，再允许提交；给合成事件添加独立来源标记。0.2.1 仅针对左右箭头键码123/124的主键事件加入 `maskSecondaryFn` 平台导航标志，修饰键事件不添加该标志；不改变用户保存的逻辑快捷键。
- `SideButtonSystemAdapter`：订阅公开的其他鼠标按下/抬起/拖动事件，预检发出输入的权限，同步提交完整键盘序列，不改写系统快捷键。
- `SideButtonEngine`：权限预检、公开 session/headInsert event tap、主线程运行循环、状态提示、暂停与资源释放。

滚动监听只订阅滚轮，本模块只订阅其他鼠标按键；两者独立。不因为原滚动反转软件运行就阻止侧键模块。

## 安全与验收边界

来源策略检查 PID、tag 和来源状态，拒绝已标记的合成或私有来源。这是公开元数据过滤，不是不可伪造的物理设备证明，不能排除其他驱动伪装或缺省字段。

成功接管后会消费完整鼠标按下/抬起对，失败则保留原对；键盘序列完整构造并通过预检后才提交。`CGEvent.post` 没有系统送达确认，返回成功仅代表提交完整序列，不证明系统已切换桌面。

普通设置关闭时，若已接管的按键仍按住，会显示等待释放并只排空该配对；若释放丢失或设备断开，可能继续等待。显式引擎 `stop()`、应用退出及析构立即释放监听，不依赖后续鼠标释放。系统停用及连续超时会安全暂停，需手动关闭后再开启；迟到旧回调不重启监听。

离线测试使用真实但不向系统发送的 CGEvent、本地普通 Mach 端口及注入发送器，不实际安装全局 event tap，不操作系统权限或切换桌面。生产 AppDelegate 的按钮和保存流程另用独立应用身份验证，避免改动用户正式偏好。

本机实际鼠标采样得到按钮3/4、PID0、来源状态1、标记0。原序列已发出但系统不切换；保持原安装版和签名不变，仅在临时运行时诊断层给箭头主键加 `maskSecondaryFn` 后，用户确认能切换，且收到 `NSWorkspace.activeSpaceDidChangeNotification`。正式0.2.1在构造器中写入同一修正，适配器去除该平台位还原逻辑组合、再重建序列严格验证；非箭头快捷键不能借此携带Fn。诊断层不随应用交付。

多显示器、全屏应用、其他鼠标厂商驱动兼容性仍需单独验收。源码编译、事件构造、单元测试与界面截图都不能替代物理验收。

## 用户验收

1. 在“关于与权限”中手动授权辅助功能。
2. 确认系统 ⌃← / ⌃→ 能切换桌面，并至少有两个桌面。
3. 开启侧键总开关，查看页面状态是否显示已启用。
4. 单击两个侧键，检查左右切换；再验证方向互换。
5. 关闭总开关，确认网页前进／后退恢复。若状态提示等待释放，松开侧键；异常时退出轻栏可立即释放监听。
6. 测试时不要同时用其他鼠标映射软件接管相同侧键。
